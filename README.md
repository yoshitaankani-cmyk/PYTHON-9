# Tuple-Based Product Catalogue Audit

## About the Project
The Tuple-Based Product Catalogue Audit system is designed to maintain product details using tuples. It calculates inventory values and identifies products that require stock replenishment.

## Objectives
- Store product IDs, prices, and stock quantities.
- Organize product information using tuples.
- Calculate the inventory value of each product.
- Identify products with low stock.
- Calculate the total inventory value.

## Concepts Used
- Variables and data types
- Tuples
- Tuple unpacking
- Lists
- For loops
- Conditional statements

## How the Program Works
1. The user enters the number of products.
2. Product IDs, prices, and stock quantities are collected.
3. Product details are stored in tuples.
4. Tuple unpacking is used to access individual product details.
5. Inventory value is calculated by multiplying price and stock quantity.
6. Products with fewer than five items are identified.
7. The total inventory value is displayed.

## Conclusion
This project demonstrates how tuples and tuple unpacking can be used to organize product information and perform inventory calculations in Python.
